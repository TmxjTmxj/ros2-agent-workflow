# 与现有 Agent-MCP-ROS2 项目的对比

> 本对比只陈述公开仓库中可复核的功能边界，不评价任何项目的工程质量或模型能力。
> 不同项目定位不同：有些是通用工具库，有些是机器人管理平台，有些是研究原型。
> 本仓库的定位是：**面向完整机器人任务的受控、安全、可验证参考实现**。

## 样本选择

对比对象包括 GitHub 上公开、以 Agent 通过 MCP 控制 ROS2 为主要目标的代表性项目：

- `wise-vision/ros2_mcp`
- `LCAS/ros2_mcp`
- `mergeos-bounties/ros2-mcp`
- `publu/RoboRun`
- `ai2robot-network/ros2-mcp`
- `kubja/ros2_mcp_gateway`

样本仅用于定位差异，不构成排行榜。

## 对比表

| 能力维度 | 本仓库 | 通用 ROS2 MCP 工具库 | 行为/平台型项目 |
|---|---|---|---|
| MCP 工具边界 | 12 个有界任务工具，类型 schema，禁止 shell / 任意 topic / 任意 payload | 通常提供 list/publish/subscribe/call 等通用工具 | 提供 see/move/ask 或配置化工具 |
| 运动控制归属 | `mission_controller` 单写入者，Agent 不能直接发 `/cmd_vel` | Agent 可发布任意话题消息 | 由平台或运行时封装 |
| 安全机制 | `SafetyGateway` 状态机、激活许可、心跳、急停闩锁、完整审计 | 多数未实现完整安全状态机 | RoboRun 有安全钳位，其他不一致 |
| 失败行为 | Fail-Closed：任何异常进入安全停止，并记录稳定错误码 | 通常直接返回工具错误 | 部分有飞行记录 |
| 机器人模型 | 官方 TurtleBot3 Burger `DiffDrive`，真实轮关节与轮速里程计 | 不绑定模型 | RoboRun 为 MuJoCo 狗/自定机器人 |
| 参考案例 | 医院三段送药完整任务，起点/终点/路线/容差/时限明确 | turtlesim、topic echo 等基础示例 | 跟随/导航等行为示例 |
| 独立验收 | 独立里程计、五路接触传感器、控制器 GID、前后相机、停车漂移 | 通常无独立验收器 | RoboRun 有运行记录，其他部分有 proof |
| 终态证据 | 先冻结终态快照，再清理进程，避免取证竞态 | 未形成完整终态协议 | 部分有 proof/黑盒 |
| 时钟语义 | ROS `/clock` 管赛题预算，墙钟只做慢宿主机/失联保护 | 通常无显式双时钟设计 | 未明确 |
| 测试门禁 | 505 个唯一测试，分层可复现 | 多数无完整测试说明 | 不一致 |
| 文档与可视化 | 架构图、安全状态机、真实坐标路线图、演示视频、数据口径说明 | 各有 README | 各有 README/截图 |

## 本仓库的优势

1. **安全是内置的，不是事后提醒**

   通用工具库把控制权交给 Agent；本仓库通过 `SafetyGateway`、激活许可、
   心跳监控和急停锁存保证 Agent 指令必须经过有界安全平面，任何异常都
   Fail-Closed。

2. **运动控制不依赖 Agent 实时推理**

   路线跟踪运行在固定频率的 ROS2 节点中；Agent 只负责发现、授权、启动、
   查询和停止。LLM 延迟不会影响机器人的实时闭环。

3. **完成了一个可验证的完整赛题案例**

   大多数项目交付的是“工具”或“平台”；本仓库交付的是一个从自然语言任务
   到独立验收证据的完整闭环。面试官可以沿
   `profile → route → controller → acceptance_report → mcp_agent_trace`
   一路复核。

4. **证据防伪和终态一致性**

   独立验收器不信任控制器自报；终点误差、GID、接触、相机、停车漂移均
   独立采样。任务成功后先冻结证据再清理进程，避免“成功但没证据”的竞态。

5. **工程可复现**

   505 个唯一测试分层执行，colcon 隔离构建，精确 PID/PGID 进程生命周期，
   公共文档说明每个数据口径。

## 本仓库不做什么

- 不暴露任意 shell、任意话题发布或任意服务调用工具
- 不声称已经部署到真实机器人或通过官方裁判系统
- 不替代 Nav2、MoveIt 或机器人厂商驱动；真机部署时替换适配器即可
- 不做多机器人调度或云端机器人平台

## 定位一句话

> 通用 ROS2 MCP 工具库解决“能不能控制”；
> 本仓库解决“如何安全、可验证、可复现地控制”。
